# Calculadora JavaScript

## 📌 Descrição

Este projeto é uma calculadora desenvolvida em JavaScript puro com foco na implementação da lógica de processamento de expressões matemáticas.

O objetivo principal do projeto foi construir o mecanismo de cálculo manualmente, sem utilizar `eval()` ou bibliotecas externas, implementando:

* processamento de entrada
* controle de estados
* parser de expressão matemática
* conversão para notação pós-fixa
* avaliação utilizando pilha

O projeto foi desenvolvido com fins de estudo de lógica de programação e estruturas utilizadas em interpretadores de expressão.

---

## 🚀 Funcionalidades

* Entrada de números inteiros e decimais
* Operações matemáticas:

  * Adição (`+`)
  * Subtração (`-`)
  * Multiplicação (`x`)
  * Divisão (`/`)
* Suporte a números negativos
* Precedência correta de operadores
* Substituição de operador
* Remoção de caractere (*backspace*)
* Reset da calculadora
* Tratamento de erros (ex: divisão por zero)

---

## ⚙️ Tecnologias utilizadas

* HTML
* CSS
* JavaScript (Vanilla JS)

---

## 🧠 Conceitos implementados

Durante o desenvolvimento foram aplicados diversos conceitos de lógica e computação:

* **Máquina de Estados (Finite State Machine)**
* **Tokenização de expressão matemática**
* **Algoritmo Shunting Yard (Dijkstra)**
* **Notação Pós-Fixa (Reverse Polish Notation)**
* **Avaliação de expressão utilizando pilha**
* **Reconstrução de estado (State Replay)**

---

## 📂 Estrutura da lógica

O fluxo principal do sistema funciona da seguinte forma:

Entrada do usuário
↓
Processamento da entrada
↓
Validação de estados
↓
Formatação da expressão
↓
Conversão para notação pós-fixa
↓
Execução da expressão
↓
Exibição do resultado

---

## 📸 Interface

A calculadora possui uma interface simples com display horizontal rolável para suportar expressões longas.
